## What happened today
- **clai for Mac** (`apps/mac`): a SwiftUI menu bar app over the same engine. This month's spend sits next to the tally in the menu bar (today's, or the tally alone, in Settings). The panel has:
  - the month on a green card, with its basis, the change against last month, the pace to month end and a budget ring;
  - pills for today, 7 days and plan value;
  - a 30-day chart;
  - a breakdown by tool, model and project, plus tips.

  Settings cover the menu bar figure, live updates, the refresh interval, plans, budget, open at login and update checks. Live updates watch the tools' log folders with FSEvents.
- **Engine contract**: `clai snapshot [--scan]` prints one JSON document (schema 1, `apps/server/src/snapshot.ts`). The app embeds Node 24 LTS and `scripts/bundle-engine.mjs`'s single-file CLI and shows only what the engine computes. `apps/server/src/snapshot.test.ts` writes `apps/mac/Tests/ClaiKitTests/Fixtures/snapshot.json`, which the Swift tests decode.
- **Builds and releases**: `.github/workflows/mac.yml` runs on GitHub's `macos-26` runners: npm build, `swift test`, `apps/mac/scripts/package.sh`, a smoke test of the packaged app, and screenshots. `package.sh` builds per-architecture DMGs and zips, signed ad hoc. A `mac-v*` tag publishes a GitHub release.
- **Site**: `apps/site` is plain static files deployed as Vercel project `getclai` (https://getclai.vercel.app, root directory `apps/site`). It carries the download (redirects to the latest release), `install.sh`, the real August figure with its basis, and how the app works.
- **cobank.ai**: the founder decided clai and cobank.ai stay separate for good. The hosted URL is now https://clai-cloud.vercel.app, and the hosted landing page no longer mentions cobank.ai.
- **0.4.0 shipped, then quieted.** `mac-v0.4.0` is published (DMGs, zips and checksums; the site's links resolve) and `main` carries it. The founder found it too bubbly and saw "$0" in the menu bar while the panel showed the right numbers: today's figure on a morning without usage. 0.4.1, on the branch, drops the bubbles (decision "No bubbles; the Mac app and its site get quieter") and shows the month in the menu bar by default. The screenshot case `screen-update-0/1` (`apps/mac/scripts/screenshots.sh`) shows the menu bar label following a live refresh. App releases now take their version from the tag.
- **What the Mac cannot see.** The founder's heavy day ran in cloud sessions, whose transcripts stay on Anthropic's machines, so the app showed $0 for today. It now says so ("none on this Mac", hover text, Settings, site FAQ). Counting cloud sessions would need them to report themselves through a clai server (decision of 2026-10-19). Opus 5.5, Sonnet 5.5 and Haiku 5.5 joined the catalog (Opus 5.5 had been priced as Opus 5), and a catalog change now reprices stored usage on the next scan.
- **CI fix**: CI on `main` had been red since 0.3.0 because the `@claii/dashboard` pins had drifted and npm 11 rejected the lock file. Every package is now 0.4.0 with matching pins.
