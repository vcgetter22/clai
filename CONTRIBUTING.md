# Contributing to clai

## Setup

```bash
npm install
npm run build
npm test
npm run clai -- scan     # run the CLI from source
```

Node 22.13 or newer. No native modules; SQLite comes from `node:sqlite`.

## Adding a connector

Connectors live in `packages/connectors/src/{local,api,import}/`. Implement one of the interfaces in `src/types.ts`:

- **LocalConnector**: `detect(ctx)` says whether the tool's files exist; `scan(ctx, opts)` yields `RawUsageEvent`s incrementally (use `readFileState`/`writeFileState` for per-file offsets).
- **ApiConnector**: `credentials` declares keys (with `envVar` fallbacks), `verify()` makes one cheap request, `pull()` yields bucketed events and saves cursors in `ctx.state`.
- **ImportConnector**: `canImport(path, head)` sniffs the file, `import()` yields events with `cost.confidence = 'estimated'` when tokens are inferred.

Rules that every connector follows:

1. **Never read content.** Extract token counts, model ids, timestamps and labels only. Prompt or response text must not be parsed into memory beyond the usage fields and must never be stored or logged.
2. **Deterministic `naturalKey`** per event, so re-runs are idempotent (the store derives the id from `source + naturalKey`).
3. **Token convention** (see `packages/core/src/types.ts`): `input` is billable uncached input. OpenAI and Google report input inclusive of cached tokens; subtract them. `output` includes reasoning tokens.
4. **Tests with fixtures** next to the source, using temp directories for files and an injected `ctx.fetch` for HTTP. No network in tests.
5. Register the connector in the folder's `index.ts` and add a row to `docs/connectors.md`.

## Pricing catalog

Anthropic entries in `packages/core/src/pricing/catalog.ts` are hand-curated and verified against the official pricing page. Other providers come from `catalog.research.json`, generated by `node scripts/merge-pricing.mjs` from `research/pricing-catalog.draft.json`. Add a `source` URL and set `verified` honestly. The catalog integrity test rejects alias collisions.

## Style

TypeScript strict with `noUncheckedIndexedAccess`; ESM; no default exports for connectors; small pure functions in core; SQL in the store only. Keep user-facing copy plain: name things by what people recognize.

## Pull requests

Include the test output and, for connectors, a redacted sample of the source data shape (field names only, never content).
