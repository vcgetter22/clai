**New: what claude.ai and your cloud sessions are worth, estimated.** Pro and Max plans have no usage report, but claude.ai, the Claude apps and cloud sessions fill the same weekly limit as Claude Code on your Mac, whose cost clai knows exactly. With *Show Claude plan limits* on, clai measures what 1% of your week costs at API prices on your own Claude Code use, and scales the week's percent to everything else.

- The month card adds "≈ $X more on claude.ai and in the cloud, estimated"; Claude's limits show the week's total and the measured rate; plan value shows the multiple with it. The exact figures stay as they were.
- It needs a few sessions of Claude Code in Terminal to measure, and says so until then. Use beyond this Mac is counted when Claude Code next runs.
- It is an estimate: Anthropic does not publish what a percent of a plan is worth, and the limit may weigh tokens differently from API prices.
