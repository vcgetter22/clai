**New: Claude in the cloud.** Chats on claude.ai and Claude Code sessions in the cloud leave no logs on your Mac; clai now uses Anthropic's two official sources for them. Both are off until you turn them on in Settings.

- **Claude plan limits** (Pro, Max, Ultra): how much of your 5-hour and weekly limits you have used, which counts everything your plan covers: claude.ai, the Claude apps, cloud sessions and Claude Code. Turn on *Show Claude plan limits*: clai becomes Claude Code's status line command, runs your own status line as before, and puts your setting back when you turn it off. The limits update while you use Claude Code in Terminal.
- **Organization usage report** (Claude Console or Claude Enterprise): paste an Admin API key or an Analytics API key and clai prices the organization's claude.ai chats, cloud sessions, Cowork, Claude Design, Slack and API usage from Anthropic's usage report, hour by hour, next to your local tools. Claude Code and Cowork usage already in this Mac's logs is never counted twice. Enter your e-mail address to count only your own usage. The key stays on your Mac and is used only to read the report.
- ⌘C and ⌘V work in Settings.
