Nothing to sign up for. Your usage stays on your Mac.

clai has no account and sends no telemetry. It reads the files your tools already write and keeps its own database in ~/.clai.

  • Reads token counts, model names, timestamps and project folder names.
  • Never reads your prompts, code or the replies you get.
  • Prices with a catalog of 147 models, cache and long-context rules included, labelled API-equivalent.
  • Talks to the internet only to ask GitHub once a day whether a newer clai exists, and you can turn that off.

Installing

The first time you open clai

clai is not notarized by Apple yet, so macOS says it cannot check clai for malicious software. Click Done, open System Settings → Privacy & Security, scroll to the message about clai and click Open Anyway, then confirm. macOS remembers the choice.

The Terminal install above avoids the prompt because files that curl downloads are not marked as coming from the internet.

Apple silicon or Intel?

Apple menu → About This Mac: a chip named M1 or later is Apple silicon; an Intel processor needs the Intel version. Both need macOS 14 Sonoma or later.

Why is the download 32 MB?

clai brings its own copy of Node.js to run the pricing engine, so there is nothing else to install. Installed, it takes about 140 MB, nearly all of it Node; the app itself is a few megabytes of Swift. The Intel download is 34 MB.

Checking the download

Every release lists SHA-256 checksums on GitHub. In Terminal: shasum -a 256 ~/Downloads/clai-mac-arm64.dmg

Removing clai

Quit clai from its menu, drag clai from Applications to the Trash, and delete the ~/.clai folder if you also want its database gone.
